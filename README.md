# You've Got This, Omar 🌅

A small personal website made to cheer on a friend the night before a big day — built with nothing but plain HTML, CSS, and JavaScript.

## Features

- 🌌 Ambient night sky background with twinkling stars and a passing shooting star
- ☀️ Interactive sunrise — click to bring in the dawn, with a message that changes after
- ✨ Poppable fireflies mini-game
- ✅ Auto-checking recap of the day's effort
- 🫁 Guided breathing exercise to help settle a racing mind before bed
- 💌 A flip-open letter with a personal note
- 💬 Rotating encouragement quotes
- 🎵 Embedded Spotify playlist made just for him
- 🎉 Confetti cheer button

## Tech Stack

- HTML5
- CSS3 (vanilla, no frameworks)
- Vanilla JavaScript (no libraries)
